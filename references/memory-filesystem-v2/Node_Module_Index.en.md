# Node / Module index format

## Template

```md
# <Title>

<Responsibility summary>

## Related modules and nodes

### Related

#### [<Related title>](<path>/index.md)
<Related responsibility summary>

### Sub

#### [<Child title>](<path>/index.md)
<Child responsibility summary>

## Bug

### [<Bug ID> <Title>](bugs/<id>.md)
<Copied bug phenomenon>

Status: <Open|InProgress|Pending|Resolved|Unfixable>

## Todo

### [<Todo ID> <Title>](todos/<id>.md)
<Copied requirement>

Status: <Open|InProgress|Done>

## Idea

### [<Idea ID> <Title>](ideas/<id>.md)
<Copied idea text>

Status: <Proposed|Accepted>
```

Use `NULL` when a section is empty. Related contains related nodes; Sub contains direct children. Bug, Todo, and Idea entries are generated by code.

## Complete example

```md
# Bug button

Submits defect feedback for the current node.

## Related modules and nodes

### Related

#### [Sidebar](../../Sidebar-module/index.md)
Provides module navigation and switching.

### Sub

NULL

## Bug

### [B002 Repeated clicks create duplicate feedback](bugs/B002.md)
Repeated submission clicks create duplicate records.

Status: Pending

## Todo

### [T002 Show feedback submission state](todos/T002.md)
Show progress and prevent repeated submission while a request is active.

Status: InProgress

## Idea

### [I002 Include the current node with feedback](ideas/I002.md)
Reduce the location details the user must enter manually.

Status: Proposed
```
