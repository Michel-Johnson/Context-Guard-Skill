# 第一版之后的 To-Do

第一版已经锁死：会话、坏例、任务、地图。下面这些现在不做，以后单独开。

## 1. 首次建图（最难，也最要紧）

人第一次把已有仓库变成地图。

要解决的：Agent 得看懂软件怎么拆，不是列目录；第一页只有 4–8 张主干；下面按真实开工面拆，不要空壳。人在工作台里看图、点头，不在命令行里确认。

现在工作台里的「分析」还是演示，没有真的读仓。这一项以后单独做，不塞进第一版四块的日常读写。

## 2. 优化检索

多查时不要连跑 N 次 `jump`。慢的是每次起 Python（OpenClaw 夹具一次子进程约 26ms），不是文件数量。

已经做的：

- Agent 先读一份 `jump-index.json`（路径 + 坏例 + 任务），再只打开命中的 Markdown
- 仍要脚本时一次查完：`python3 scripts/map_owns.py jump --json '{"path":[...],"bug":[...],"task":[...],"last":true}'`
- 计时见 `fixtures/openclaw/JUMP-SPEED.md`

以后若还慢，再看：`open` 是否太长、有没有扫完全部 `bugs/`、从人一句话到打开正确那一份实际卡在哪。超链接仍然只给人看。

## 3. CI/CD 测试（第五块）

第一版没有这一块。以后可能作为第五部分：改完代码怎么自动验、失败怎么回到坏例。

现在明确不做：测试中台、功能链、Stop-hook 门禁。仓库里旧的那套先不动、不扩。

做的时候要接上现有四块：测试失败 → 坏例索引；常跑的验法 → 任务说明书里的命令；不要另做一本平行登记册。
