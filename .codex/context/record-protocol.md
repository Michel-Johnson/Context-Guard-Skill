## 1. 自动记什么（先定范围）

要拍的三件事：每个项目默认留下什么；明确不留什么；「自动」是 Agent 直接写进仓库，还是先出现在工作台里等人点头。

### 人已点名要记的（第 1 题正题）

1. **人说过的话、给过的文件和图片**（全部历史）。太长的做摘要或索引，不要把原文整段反复贴进下一轮。图片/文件只记仓库里的路径，不把二进制拷进记忆目录。密钥不记。
2. **query 里的 bug**：不管这轮修好没修好，都要提炼，写下修的经验，做成**坏例索引**。以后再遇到，先查索引；历史上修过像的，先看那条经验。
3. **Agent 每一次回复的摘要**。

画布上怎么点 Done、细卡藏不藏，先放到后面（第 4 / 9 题）。这里只定「记什么」。

隐藏/删除有两种完全不同的意思，不能混：

- **只是不想看**：从图上拿掉，底稿还在，Agent 改文件时还能找到。
- **这条是错的**：就是为了不让 Agent 再看见。这种必须从 Agent 下次能读的索引里拿掉（或标成作废），不能当「藏着还能用」。

### 我认为还要记的（请拍板）

光有上面三样，会变成一本按时间排的日记。下一轮很难从日记里判断「现在软件怎么拆、这块现在还兴哪条规矩」。所以还缺：

4. **软件怎么拆的那张图**（模块、从属、一句用途）。人的话和坏例要挂在某块软件上，查的时候才不是通篇搜日记。
5. **现在还生效的短规矩**。不是回复摘要，是「这块以后就这么干 / 别再这么干」。挂在对应那块上。人纠正过的全局说法也算。
6. **改某个文件时先看哪一块**。否则有了索引也不知道先打开哪条。
7. **人标成错的东西**。见上面第二种隐藏：Agent 下次当它不存在。

### 对第 3 条的收紧（请拍板）

不建议把每一次回复都做成摘要长期留着。Agent 说错的、试过又丢掉的，会把有用的经验淹没。建议改成：

- 只摘要**真正留下痕迹**的回复：改了代码、改了图、写下或修了坏例、立了短规矩；
- 或者一轮结束写一份很短的摘要，而不是每条回复一份。

第 1 条也不把原文当唯一真相：默认是**索引**（谁、大概说了什么、附件路径、挂到哪条坏例/哪块软件）。原文太长就只留摘要。下一轮按索引跳，不要把历史 query 全贴进去。

第 2 条：坏例索引就是坏例小文件 + 地图上的桩，不要另做一本总清单。已修、未修都留经验；再遇到先查。

明确不记：密钥、二进制本身、整张地图/全部历史原文贴进下一轮、测试中台。

## 2. 一条「短规矩」长什么样

- 检查器里那一两句话，算不算唯一格式？要不要编号？
- 什么时候允许写成单独文件？（太长、有步骤、有反例）
- 人改了一句，Agent 下次是覆盖、追加，还是另开一条？

## 3. 文件怎么摆（Agent 怎么跳）

- 人改图仍写 `map.json`，Agent 走 `cards/` + `bugs/` + `owns-index.json`，这一层还要不要改？
- 投影（`cards/`）是每次人保存就生成，还是 Agent 读之前再生成？
- 新会话默认只读已授权的卡，这句话还成立吗？

## 4. 怎么更新、谁说了算

- Agent 提议改记忆：灰色草稿，人点两次才进图——坏例和短规矩是否同一套？
- 人在 HTML 里改了，和 Agent 在 markdown 里改了，以谁为准？
- 过时的规矩是删掉、标废弃，还是挪到休眠？

## 5. 坏例本身记什么、存在哪

- 标题之外，正文最少要哪几行？（现象、触发、根因、修复、守卫、证据）
- 未修 / 已修 / 先不做，这几个状态够不够？
- 截图还是只记仓库相对路径、文件放 `docs/shots/`？

## 6. 人怎么提出一条坏例

- 在 Map 上点某张卡加标题：Agent 何时补正文？补完要不要人再确认？
- 在会话里随口说「这里有个 bug」：Agent 怎么判断挂在哪张卡？不确定时问人还是挂在当前正在改的文件那张卡？
- 同一句话算新坏例还是已有那条的复发？

## 7. Agent 怎么去修

- 先读：主卡短规矩 → 链上几层 → 这篇坏例正文。还要不要自动打开邻居卡？
- 修的时候这条坏例怎么标成「本会话在修」？
- 人没点授权的卡，能不能为了修 bug 去读、去改？

## 8. 修好之后经验怎么沉淀

- 坏例改成已修，正文里补修复和守卫，文件留下——这样够不够？
- 「执行完的经验」是休眠经验、一条新的短规矩，还是两者都要？
- 休眠经验平时不进检查器，什么时候允许 Agent 再打开？

## 9. 人确认和 Agent 自作主张的边界

- 哪几类写入必须等人在 HTML 里确认？（新模块、新坏例正文、删除、改 owns）
- 哪几类可以 Agent 当场写下再通知？（现象摘录、证据路径、会话里刚说的原话）
