# 每个项目自动记什么（讨论清单）

一条记忆/坏例挂多张卡，等真实场景遇到再做。下面按生命周期排队，一次只拍一项。

状态：未决。人确认后再写进约定。

## 1. 自动记什么（先定范围）

要拍的三件事：每个项目默认留下什么；明确不留什么；「自动」是 Agent 直接写进仓库，还是先出现在工作台里等人点头。

### 提案（待确认）

人看的是**软件怎么拆**，不是给 Agent 新长出来的每张小卡点头。工作台是给人看设计的；Agent 底下可以更细，不必和画布上每一张卡一一对应。不要做成两份互相打架的地图：还是一份底稿，人看见的是滤过的设计面。

每个项目默认留下的：

1. **设计面（给人看）**：模块怎么拆、从属、那句用途、模块之间谁给谁东西。第一次用和以后结构真变了，才需要人看一眼。
2. **底稿（给 Agent 跳）**：哪张卡负责哪些源码、更细的开工/文件卡、坏例正文、跳转用的复印件。Agent 可以自己写下；人没选中的**先藏着，不删**。改文件时 Agent 仍可按路径找到藏着的卡。
3. **卡片上的短规矩**。只在「人说记住 / 人纠正了做法 / 修好坏例后要防再犯」时写。不是把推理过程记上去。
4. **坏例**。人在图上起了标题，或会话里明确说这是要留下的问题。地图上留桩，正文单独小文件。
5. **人反复纠正的全局说法**。进 `user-messages.md`。闲聊整段不搬。
6. **附件只记路径**。二进制不进记忆目录。

**不自动写「会话切片」文件。** 真要留下的，升级成短规矩或坏例。对话原文会话结束就丢掉。

明确不记：聊天全文、密钥、被否掉且你明确不要的方案、整张地图贴进下一轮、测试中台、同一条记忆往多张卡上摊。

人怎么点头——尽量少碰节点，一次收工：

- Agent 更新后，画布上只把**本轮新冒出来的、设计粒度的东西**摊给你看（新模块、拆法变了、新的用途那一句）。不是把每个文件胶囊都拉出来点一遍。
- 你点一下要留在设计面上的；然后点 **Done**。没点中的**隐藏，暂时不删**。Agent 底稿里还在。
- 文件归谁管、更细的子卡，默认进隐藏底稿，**不必每张都审**。只有拆法让人看不懂、或两块不该分开时，才出现在设计面上等人看。
- 你已经在检查器里改过的字、贴过的附件，那一下就是确认。

「自动」分三档（按上面改过）：

| 档 | 什么时候 | 例子 |
| --- | --- | --- |
| Agent 立刻写入底稿 | 不写会话一断就丢 | 文件归谁管、细卡、坏例正文草稿。人没看见不等于不存在 |
| 人点 Done 才上设计面 | 改了你看见的软件拆法 | 新模块留在画布上；没选中的藏起来 |
| 机器复印件 | 底稿已经有了 | 重生成跳转小文件 |

- 藏起来的卡，下一轮 Agent 改对应文件时能不能直接当规矩用，还是只当路标、规矩仍以上面那张可见模块为准？

## 2. 一条「短规矩」长什么样

- 检查器里那一两句话，算不算唯一格式？要不要编号？
- 什么时候允许写成单独文件？（太长、有步骤、有反例）
- 人改了一句，Agent 下次是覆盖、追加，还是另开一条？

## 3. 文件怎么摆（Agent 怎么跳）

- 人改图仍写 `map.json`，Agent 走 `cards/` + `bugs/` + `owns-index.json`，这一层还要不要改？
- 投影（`cards/`）是每次人保存就生成，还是 Agent 读之前再生成？
- 新会话默认只读已授权的卡，这句话还成立吗？

## 4. 怎么更新、谁说了算

- Agent 提议改记忆：灰色草稿，人点两次才进图——坏例和短规矩是否同一套？
- 人在 HTML 里改了，和 Agent 在 markdown 里改了，以谁为准？
- 过时的规矩是删掉、标废弃，还是挪到休眠？

## 5. 坏例本身记什么、存在哪

- 标题之外，正文最少要哪几行？（现象、触发、根因、修复、守卫、证据）
- 未修 / 已修 / 先不做，这几个状态够不够？
- 截图还是只记仓库相对路径、文件放 `docs/shots/`？

## 6. 人怎么提出一条坏例

- 在 Map 上点某张卡加标题：Agent 何时补正文？补完要不要人再确认？
- 在会话里随口说「这里有个 bug」：Agent 怎么判断挂在哪张卡？不确定时问人还是挂在当前正在改的文件那张卡？
- 同一句话算新坏例还是已有那条的复发？

## 7. Agent 怎么去修

- 先读：主卡短规矩 → 链上几层 → 这篇坏例正文。还要不要自动打开邻居卡？
- 修的时候这条坏例怎么标成「本会话在修」？
- 人没点授权的卡，能不能为了修 bug 去读、去改？

## 8. 修好之后经验怎么沉淀

- 坏例改成已修，正文里补修复和守卫，文件留下——这样够不够？
- 「执行完的经验」是休眠经验、一条新的短规矩，还是两者都要？
- 休眠经验平时不进检查器，什么时候允许 Agent 再打开？

## 9. 人确认和 Agent 自作主张的边界

- 哪几类写入必须等人在 HTML 里确认？（新模块、新坏例正文、删除、改 owns）
- 哪几类可以 Agent 当场写下再通知？（现象摘录、证据路径、会话里刚说的原话）
