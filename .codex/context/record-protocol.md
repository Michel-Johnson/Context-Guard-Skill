## 1. 自动记什么（先定范围）

要拍的三件事：每个项目默认留下什么；明确不留什么；「自动」是 Agent 直接写进仓库，还是先出现在工作台里等人点头。

### 提案（待确认）

每个用 Context Guard 的项目，默认有这几样——不是每聊一句就记，是**系统里该有、该更新的时候就有**：

1. **地图**（卡片、从属、用途那一句）。第一次用时 Agent 分析仓库出草稿，人在 HTML 里点头后才算正式图。
2. **文件归谁管**（哪张卡负责哪些源码路径）。建图时 Agent 按目录提议；有冲突等人裁。后面改文件才找得到该读哪张卡。
3. **卡片上的短规矩**。只在「人说记住 / 人纠正了做法 / 修好坏例后要防再犯」时写。不是把推理过程记上去。
4. **坏例**。人在图上起了标题，或会话里明确说这是个要留下的问题。地图上留桩，正文单独小文件。
5. **人反复纠正的全局说法**（怎么说话、产品红线）。进 `user-messages.md`。工作台里暂时没有「确认这句话」的按钮，Agent 可以当场写；写错了人下一句改掉。不要把闲聊整段搬进去。
6. **附件只记路径**。人在 HTML 里贴了图或文件，只写仓库相对路径；二进制放 `docs/shots/` 一类地方，不进 `.codex/context/`。

给 Agent 跳转用的 `cards/`、路径索引，是地图的**复印件**，不是又一份要人编的记录。正式图一保存就重生成。

**不自动写「会话切片」文件。** 这一轮真正要留下的，升级成某张卡上的短规矩或一条坏例。对话原文、思考过程，会话结束就丢掉。首次用的架构长文可以有一份，那是建图用的，不是每次开发的日记。

明确不记：

- 聊天全文、Agent 推理、被否掉的方案
- 密钥、token、`.env`
- 人没点头的灰卡片——可以当草稿留着，下一轮不当正式记忆用
- 整张地图、坏例总清单贴进下一轮对话
- 二进制拷进 `.codex/context/`
- 测试中台 / 功能链 / 同一条记忆往多张卡上摊（后一项等真遇到再谈）

「自动」分三档，不要混成一句「Agent 自己写盘」：

| 档 | 什么时候 | 例子 |
| --- | --- | --- |
| 草稿可立刻落盘 | 会话可能中断，不写就丢 | 提议的新模块、坏例正文草稿。下一轮仍当未确认，灰色，不当正式规矩 |
| 人在 HTML 里点过头才算正式 | 改了图的结构或正式记忆 | 新模块进图、删卡、文件归谁管、短规矩正式生效、坏例标题和路径 |
| 机器复印件，不用点头 | 正式图已经有了 | 重生成 `cards/` 和路径索引 |

人已经在检查器里改过的字、贴过的附件路径，那一下就是确认，不必再问一次。

## 2. 一条「短规矩」长什么样

- 检查器里那一两句话，算不算唯一格式？要不要编号？
- 什么时候允许写成单独文件？（太长、有步骤、有反例）
- 人改了一句，Agent 下次是覆盖、追加，还是另开一条？

## 3. 文件怎么摆（Agent 怎么跳）

- 人改图仍写 `map.json`，Agent 走 `cards/` + `bugs/` + `owns-index.json`，这一层还要不要改？
- 投影（`cards/`）是每次人保存就生成，还是 Agent 读之前再生成？
- 新会话默认只读已授权的卡，这句话还成立吗？

## 4. 怎么更新、谁说了算

- Agent 提议改记忆：灰色草稿，人点两次才进图——坏例和短规矩是否同一套？
- 人在 HTML 里改了，和 Agent 在 markdown 里改了，以谁为准？
- 过时的规矩是删掉、标废弃，还是挪到休眠？

## 5. 坏例本身记什么、存在哪

- 标题之外，正文最少要哪几行？（现象、触发、根因、修复、守卫、证据）
- 未修 / 已修 / 先不做，这几个状态够不够？
- 截图还是只记仓库相对路径、文件放 `docs/shots/`？

## 6. 人怎么提出一条坏例

- 在 Map 上点某张卡加标题：Agent 何时补正文？补完要不要人再确认？
- 在会话里随口说「这里有个 bug」：Agent 怎么判断挂在哪张卡？不确定时问人还是挂在当前正在改的文件那张卡？
- 同一句话算新坏例还是已有那条的复发？

## 7. Agent 怎么去修

- 先读：主卡短规矩 → 链上几层 → 这篇坏例正文。还要不要自动打开邻居卡？
- 修的时候这条坏例怎么标成「本会话在修」？
- 人没点授权的卡，能不能为了修 bug 去读、去改？

## 8. 修好之后经验怎么沉淀

- 坏例改成已修，正文里补修复和守卫，文件留下——这样够不够？
- 「执行完的经验」是休眠经验、一条新的短规矩，还是两者都要？
- 休眠经验平时不进检查器，什么时候允许 Agent 再打开？

## 9. 人确认和 Agent 自作主张的边界

- 哪几类写入必须等人在 HTML 里确认？（新模块、新坏例正文、删除、改 owns）
- 哪几类可以 Agent 当场写下再通知？（现象摘录、证据路径、会话里刚说的原话）
