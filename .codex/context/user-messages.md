## Recent User Signals

- 已有项目拆成 map 是需要的功能。
- 架构图可以竖着也可以横着。
- 从仓库建立 map 应该是用户第一次使用 Context Guard skill 的时候。
- 希望点击标题后可以切换仓库。
- 希望当前的开发过程也加载 Context Guard skill。
- 如果做过任何 PR / MR，应该要通知用户。
- 为啥每次点进来都要重新构建。
- 初始建图不是瞬间的，需要 Agent 去理解、分析整个架构。
- 现在的架构分析太简单，真实项目不会停在这一层。下面必须有大量具体节点。
- 首次加载需要让 Agent 做 markdown 一类的整仓分析；可以先做确认门，再谈 markdown 格式。
- 追求速度导致没有细拆整仓，只列了简单架构，对不上真实开发粒度。
- 点击分析后要写明这是演示，没有真实 Agent 在读仓。
- 分析的还是不够细致，粒度还是太粗了。
- 粒度变细后整页排不下：要不要限制一级模块数量；一级很多时怎么排；Agent 第一次出图会冒出看不懂的模块/子模块，要不要统一架构来约束。
- 当前前端和先前工作台设计不一致；优化要叠在原设计上（树、左右/上下、模块卡只有标题和用途），不要换成另一套栅格+卡内文件列表。
- 根目录做成网格更合理；点击模块必须进入，不能在根上展开孩子。
- 控制面 UI 不能把所有文件摊成一排；要学习如何构建子模块。
- 模块之间需要连线，否则看不出模块从属关系。文件仍不要摊在根上。
- 分析缺模块间的生产/消费关系（A 的输出是 B 的输入）；模块内部也不应只是单层列表，真实项目更像图而不是一条链。
- 要的是分支链：第一页不要铺开那么多模块。主干 4–8 张卡。模块一次只展示一层；开工节点后面还有开工节点则默认展开。多于两个分支就应该是模块。Agent 第一次生成、尚未人批的模块/节点右上角要有绿点。右侧检查器还是不够短，去掉说明文字和 Bug 描述。
- 第一页 L1 是 4–8 张卡，视仓库而定，不要写死成 4。OpenClaw 这种体量可以把 Plugins、Nodes、控制面 UI、安全也放在第一层；更小的仓可以只有 4 张主干。
- 模块下面不能只有一级两个胶囊。Linux node 这类真实开工面要先建子模块（连接 / 远程命令 / 常驻），再挂文件。
- 不要相邻同级连线；父子连线用原来的曲线，不要直角折线。
- 记忆、Bug、节点这些地方也要能附带文件和图片；用路径存储即可。
- 记忆、Bug 区块名不用编辑。开工节点上的「探索中」不知道是什么意思。右侧要能删除节点/模块，不要多余说明句。
- 不要顶栏「工作台原型 · 分析是演示」那行红字。根标题要么下面有说明，要么卡片别留那么高的空白；不要「部分」标记。

## Durable User Constraints

- Agent 记录，人确认/置顶/丢弃。
- 人在 HTML 里操作，不在 CLI。
- 不做 Test Hub / 功能链 / Stop-hook 门禁，直到工作台交互正确。
- 不要用 `window.prompt` / `confirm`。
- 模块卡只要标题和一句用途。
- Bug 是节点内容，不是子节点。
- 新会话默认很小，不要一次加载全部共享记忆。
- 回复使用中文。
- 之后会话直接打开已有地图，不要每次进来都重拆。
- 首次建图需要 Agent 理解架构，不是瞬间出图，也不是目录树。
- 分析粒度必须对齐真实开发单元；空壳三节点没有意义。
- 首次分析先写 architecture.md；L1 只是确认门，数量建议 4–8，按仓库体量定，不要写死成恰好 4 张。根目录只铺 L1。模块一次只展示一层：点进模块只画直接孩子，子模块不展开。开工节点若后面还有开工节点（最多两岔）则默认展开；结构超过两个分支就应该是模块，不是开工节点。一张卡下超过约 8 个文件就要先建子模块。模块下面不能只有一级两个胶囊（Linux node 要先拆连接 / 远程命令 / 常驻）。模块卡只要标题和用途。规则、记忆、Bug 不是节点。不要空壳 CLI / TUI / UI，也不要把文件平铺在 L1 下面。提议模块不要挂锁，锁只表示已确认但当前会话未授权。Agent 第一次生成、尚未人批的模块和开工节点，右上角要有绿点。
- 记忆、Bug、节点、休眠经验可附文件或图片；只记仓库相对路径，不把二进制写进 HTML，也不弹原生对话框。
- 当前会话尚未授权的节点整卡灰色，不要和已授权的米色模块卡长得一样。
- Agent 提议的节点要更灰、更透明，看起来像草稿，不要画成实心卡片，否则会被当成已经确认的节点。
- 点开 Agent 提议节点时，检查器只留标题、用途、加入/隐藏。已确认节点同样要短：两行用途、必要按钮；记忆/Bug 区块名不用编辑；不要把默认 dirty 显示成「探索中」芯片。Bug 只显示标题；不要面包屑、空附件、架构笔记、只看这条、移出会话。
