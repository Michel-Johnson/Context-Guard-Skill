## 规则冲突的裁决

1. 不因“采用大厂规范”绕过用户授权、安全限制或现有必需检查。
2. 专项契约仍在原文件维护；主流程只描述先后关系、证据和责任。若两份要求冲突，记录冲突并修正规范，不让 Agent 自选宽松版本。
3. 现有源码不被本文追溯判定为全部合规；新增/触及范围适用，历史欠账登记。不能借规范工作改写无关模块。
4. 规则的人工执行与自动强制分开。文档生效不等于自动化实现完成。
