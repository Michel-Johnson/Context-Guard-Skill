| 实验 | 观察 | 决定 |

## 不作出的保证

Hook 校验信息和回执是否存在，不能证明模型的语义判断或测试陈述真实。
任意脚本的外部副作用不是文件系统沙箱能由这些 Hook 阻止的；未知范围需复核。
同一 session 的真正并行写入仍需进程级事务测试和保护。Windows 真实运行结果
应以 Windows CI 为准，不能把 macOS 上的路径别名测试当成 Windows 验收。
